# Low-Noise Amplifier
A low-noise, low-distortion amplifier designed and simulated in LTspice.

## Project Overview
The amplifier was designed from scratch using BJT and MOSFET stages
with a differential input stage and resistor feedback.

## Specifications
- Voltage gain: 20×
- Load: 50 Ω
- THD: < 0.01%
- Efficiency: > 70%
- Simulation environment: LTspice

## Results
The circuit was tested in LTspice using audio signals and achieved
strong amplification while maintaining low distortion.
